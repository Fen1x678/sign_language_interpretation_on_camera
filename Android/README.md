# speech для Android (beta-0.46)

**Сурдоперевод, бесконтактное управление жестами и «Речь → текст» на телефонах Android**

> 🚧 **Бета-версия для Android.** Это перенос приложения для iPhone (beta-0.46) на Android. Алгоритмы распознавания жестов и исправления речи те же, что на iPhone, но на настоящем телефоне Android версия ещё не проверялась. Если что-то не собирается или работает не так — пришлите скриншот через [Issues](https://github.com/Fen1x678/sign_language_interpretation_on_camera/issues).

> 📱 **Нужен телефон с Android 8.0 или новее** и камерой. Для «Речь → текст» — служба распознавания речи (обычно это приложение Google).

---

## Что умеет

- **🗣 Перевод (сурдоперевод).** Человек показывает жесты, а приложение сразу выводит слова крупным текстом и произносит их вслух. Переводятся жесты, которым приложение обучили: позы и жесты с движением, одной или двумя руками.
- **🎛 Управление.** Встроенные жесты (👍 ✋ ☝️ и движения руки) управляют демо-интерфейсом без касания экрана.
- **🎙 Речь → текст.** Отдельная страница: то, что говорят вокруг, сразу появляется на экране крупным текстом. Каждая реплика после паузы — с новой строки.

### Что нового в beta-0.46

- **🎯 Меньше ошибок в жестах.** Похожие слова (одна форма кисти у подбородка и у груди) проверяются строже и не путаются. Поза засчитывается, только когда пальцы перестали двигаться, поэтому переходы между жестами не превращаются в лишние слова. Если какое-то слово стало узнаваться хуже — запишите его ещё раз или сдвиньте «Чувствительность» чуть вправо.
- **🗣 Речь человека в 10 метрах** (Android 13+, экспериментально). Кнопка 👂 «Дальняя речь» (включена сразу): приложение само слушает микрофон, усиливает тихий и далёкий голос (до 16 раз), убирает низкий гул и передаёт звук службе распознавания. Если служба распознавания на телефоне такой звук не принимает, приложение само возвращается к обычному микрофону и пишет об этом внизу страницы.
- **🎧 Микрофон Bluetooth.** Дайте говорящему наушники с микрофоном и нажмите 🎧 — его будет слышно с любого расстояния, даже в шуме.
- **🎨 Мягкий и удобный интерфейс.** Спокойные цвета (мятный, бирюзовый, янтарный, персиковый) вместо ярко-зелёного и красного, скруглённые карточки, крупные кнопки, фразы «Речь → текст» в отдельных карточках, лёгкая вибрация, когда слово переведено.

Всё то же, что в версии для iPhone:

- до двух рук по 21 точке, скелет рук поверх изображения;
- плечи находятся автоматически на каждом кадре: одна и та же форма кисти у подбородка, у груди и у плеча — разные слова;
- жест понимается у разных людей и у левшей (левая рука — зеркало правой);
- запись жестов с трёх ракурсов, предупреждение о похожих словах, подсказка «Похоже на «слово» — N%»;
- опущенная вторая рука (на столе, на коленях) не мешает жесту одной рукой: неподвижная, она не учитывается и рисуется серым, а как только поднимается или двигается — снова учитывается;
- ползунок «Чувствительность», порог для каждого слова подбирается сам;
- автоматическая подсветка в темноте: у задней камеры — фонарик, у фронтальной — экран;
- озвучка перевода на русском;
- «Речь → текст»: исправление запинок («п-п-привет» → «привет»), повторов («я хочу я хочу» → «я хочу»), растянутых звуков и звуков-пауз («ээээ», «мммм»); «Мои слова» для имён и терминов; выбор паузы для новой строки; «К новым» при чтении старого текста; продолжение после сворачивания приложения.

### Чем отличается от версии для iPhone

| | iPhone | Android |
|---|---|---|
| Точки рук и плечи | Apple Vision | Google MediaPipe (та же схема из 21 точки) |
| Распознавание речи | Apple | служба распознавания Android (обычно Google) |
| Новая строка в «Речь → текст» | по паузе в тексте | по паузе, которую определяет служба распознавания |
| Исправление слов по словарю телефона | есть | пока нет (запинки, повторы и «Мои слова» исправляются) |
| Звуковой сигнал распознавания | нет | Android подаёт сигнал при каждой фразе — приложение его приглушает (настройка «Без звукового сигнала») |
| Яркость экрана после выхода | возвращается приложением | Android возвращает сам |
| Усиление дальней речи | есть | Android 13+, экспериментально (если служба распознавания принимает звук от приложения) |
| Перевод телефонного звонка | нельзя (iOS не даёт звук звонка) | нельзя (Android не даёт звук звонка) |

Словарь жестов у Android и iPhone отдельный: жесты нужно записать заново на телефоне Android.

## Установка

### Что нужно

| Что нужно | Версия |
|---|---|
| Телефон Android | 8.0 или новее, с камерой |
| Компьютер | Windows, macOS или Linux |
| [Android Studio](https://developer.android.com/studio) | Ladybug (2024.2) или новее |
| Кабель USB | для подключения телефона |
| Интернет | при первой сборке Android Studio скачивает библиотеки |

### 1. Скачайте проект

Версия для Android лежит в ветке **`beta-0.46_only_android`**, в папке **`Android`**.

**Вариант А: архивом.** На странице репозитория слева вверху выберите ветку **beta-0.46_only_android**, нажмите зелёную кнопку **Code → Download ZIP** и распакуйте архив.

**Вариант Б: через Git:**

```bash
git clone -b beta-0.46_only_android https://github.com/Fen1x678/sign_language_interpretation_on_camera.git
```

### 2. Откройте проект в Android Studio

1. Запустите Android Studio → **Open**.
2. Выберите папку **`Android`** внутри скачанной папки (не всю папку репозитория!) и нажмите **OK**.
3. Подождите, пока внизу закончится **Gradle Sync**. В первый раз это несколько минут: скачиваются библиотеки.
4. Если Android Studio предложит обновить Android Gradle Plugin — можно согласиться или отказаться, проект соберётся в обоих случаях.

### 3. Подготовьте телефон

1. **Настройки → О телефоне** → 7 раз нажмите **Номер сборки** — включится «Режим разработчика».
2. **Настройки → Система → Для разработчиков** → включите **Отладка по USB**.
3. Подключите телефон кабелем и на телефоне нажмите **«Разрешить»** в запросе отладки.

### 4. Запустите

1. Вверху Android Studio выберите свой телефон в списке устройств.
2. Нажмите **▶ Run** (Shift+F10).
3. Приложение **speech** установится и откроется. Разрешите доступ к камере; к микрофону — когда откроете «Речь → текст».

**Без кабеля (файлом APK):** **Build → Build App Bundle(s) / APK(s) → Build APK(s)** → **locate** → файл `app-debug.apk`. Отправьте его на телефон, откройте и разрешите установку из этого источника.

## Как пользоваться

Так же, как на iPhone:

1. **«Перевод» → «➕ Словарь»** → введите слово → выберите «С движением» или «Поза» → **«Записать жест»**. После отсчёта покажите жест (запись пройдёт 3 раза: прямо, чуть левее, чуть правее).
2. Показывайте жесты в камеру — перевод появится внизу и прозвучит голосом. Опустите руки на 2 секунды — фраза закончится.
3. **🔄** — сменить камеру, **🔦** — подсветка (Авто / Всегда вкл. / Выключена), **👁** — включить/выключить распознавание, **?** — справка.
4. **«🎤 Речь → текст»** — живая расшифровка речи. Кнопки внизу: 🗑 — очистить, 👂 — дальняя речь (Android 13+), 🎤/■ — слушать/пауза, **Aa** — размер текста, 🎧 — микрофон Bluetooth. Кнопка **⋯**: «Мои слова», «Новая строка после паузы», «Дальняя и тихая речь», «Микрофон Bluetooth», «Только на телефоне (без интернета)» (Android 12+), «Без звукового сигнала».
5. **Человек далеко (до 10 метров).** Проверьте, что 👂 включена (бирюзовая), и положите телефон низом (микрофоном) к говорящему. В шуме дайте говорящему наушники Bluetooth с микрофоном и нажмите 🎧.

## Как это работает

```
Камера (CameraX) → кадр, обрезанный по видимой области → MediaPipe: 21 точка на кисть и плечи
      → сглаживание (One Euro) → признаки позы и движения → k-NN / DTW → слово или команда
      → текст, речь, действие
```

Алгоритмы распознавания (признаки, k-NN, DTW, пороги, защита от ложных срабатываний) — те же, что в версии для iPhone; подробно они описаны в [`GestureControl/README.md`](../GestureControl/README.md). Здесь они написаны на Kotlin без зависимостей от Android и проверены тестами (`app/src/test`).

Яркость сцены для автоподсветки считается по выдержке, светочувствительности и диафрагме камеры (Camera2) — в той же шкале APEX, что и на iPhone.

Дальняя речь (Android 13+): `AudioPump` записывает микрофон (`AudioRecord`, источник `VOICE_RECOGNITION`, 16 кГц), `SpeechEnhancer` (тот же, что на iPhone: фильтр гула 100 Гц, автоматическая громкость до +24 дБ, шум не громче −38 дБ, ограничитель) обрабатывает звук, и он по неблокирующему каналу уходит службе распознавания (`RecognizerIntent.EXTRA_AUDIO_SOURCE`). Между фразами звук не теряется: последняя секунда уходит в следующий запрос. Фраза заканчивается по паузе в распознанном тексте, как на iPhone. Если служба трижды сразу отказывается от звука или три запроса подряд с голосом остаются без текста (и текста ни разу не было), приложение переходит на обычный микрофон. Микрофон Bluetooth: `AudioManager.setCommunicationDevice` (Android 12+) или канал SCO (раньше).

## Структура

```
Android/
├── build.gradle.kts, settings.gradle.kts, gradle/ — сборка (Gradle)
└── app/
    ├── build.gradle.kts                     — зависимости: Compose, CameraX, MediaPipe
    └── src/
        ├── main/
        │   ├── AndroidManifest.xml          — разрешения: камера, микрофон
        │   ├── assets/                      — модели MediaPipe: руки и поза
        │   ├── res/                         — значок, название «speech»
        │   └── java/com/fen1x/speech/
        │       ├── MainActivity.kt          — точка входа
        │       ├── GestureViewModel.kt      — логика: перевод, запись жестов, подсветка, команды
        │       ├── SignStore.kt, Speaker.kt — хранение словаря, озвучка
        │       ├── camera/                  — камера (CameraX) и MediaPipe
        │       ├── core/                    — алгоритмы (чистый Kotlin): признаки, DTW, словарь,
        │       │                              встроенные жесты, исправление речи
        │       ├── speech/                  — «Речь → текст» (VoiceTranslator), дальняя речь (AudioPump)
        │       └── ui/                      — экраны (Jetpack Compose)
        └── test/                            — тесты алгоритмов
```

Тесты алгоритмов: в Android Studio правой кнопкой по папке `app/src/test` → **Run Tests**, или в терминале `./gradlew test`.

## Частые проблемы

| Проблема | Решение |
|---|---|
| `Could not find com.google.mediapipe:tasks-vision:…` или другой библиотеки | Проверьте интернет. Если версия не найдена — в `app/build.gradle.kts` поменяйте номер на тот, что предлагает Android Studio (подсветка строки). |
| `SDK location not found` | Откройте именно папку `Android` через Android Studio — путь к SDK пропишется сам. |
| Телефона нет в списке устройств | Включите «Отладку по USB», переподключите кабель, нажмите «Разрешить» на телефоне. |
| Чёрный экран вместо камеры | Настройки → Приложения → speech → Разрешения → включите **Камера**. |
| Жест не распознаётся | Запишите ещё 1–2 примера (лучше у другого человека), проверьте свет или сдвиньте «Чувствительность» вправо. |
| Жест одной рукой не узнаётся, когда видна вторая рука | Опустите вторую руку на стол или колени: неподвижная опущенная рука не учитывается (на экране она серая). Если жест записывали, когда вторая рука была видна, перезапишите его. |
| «Нет службы распознавания речи» | Установите или обновите приложение **Google**. |
| «Русский язык для распознавания недоступен» | Настройки → Система → Языки → Распознавание речи — загрузите русский, или выключите «Только на телефоне». |
| Слышен сигнал при каждой фразе | Кнопка ⋯ → «Без звукового сигнала». На некоторых телефонах сигнал идёт по другому каналу звука, и приглушить его не получается. |
| «Усиление дальней речи на этом телефоне не работает» | Служба распознавания вашего телефона не принимает звук от приложения — приложение слушает обычным микрофоном. Обновите приложение **Google**; для дальней речи используйте наушники Bluetooth (кнопка 🎧). |
| Человек далеко, текста нет | Проверьте, что 👂 включена (бирюзовая), положите телефон низом к говорящему. В шуме — наушники Bluetooth с микрофоном у говорящего и кнопка 🎧. |
| «Наушники Bluetooth не подключены» | Подключите наушники в настройках Bluetooth и снова нажмите 🎧. |
| После обновления какое-то слово узнаётся хуже | Похожие слова теперь проверяются строже, чтобы их не путать. Запишите слово ещё 1–2 раза или сдвиньте «Чувствительность» чуть вправо. |

## Что проверено

- Алгоритмы (признаки, k-NN, DTW, словарь, встроенные жесты, исправление речи, усиление дальней речи) собраны и проверены 53 тестами: позы узнаются независимо от размера и положения руки, левая рука понимается как зеркало правой, жесты с движением — по направлению и при разной скорости, неподвижная рука не считается жестом с движением, опущенная вторая рука не мешает, похожие слова (одна кисть у подбородка и у груди) не путаются, меняющаяся кисть не считается позой, тихая речь усиливается, а шум и гул — нет.
- Код Android (Compose, камера, распознавание речи, дальняя речь) проверен компиляцией против настоящего Android API 35 и Compose; CameraX и MediaPipe — по их API.
- На настоящем телефоне Android приложение ещё не запускалось.
